# JavaScript To-Do List App

A fully interactive client-side To-Do List application built using HTML, CSS, and JavaScript. This project demonstrates DOM manipulation, event handling, state management, and localStorage persistence.

## Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Filter tasks:
  - All
  - Active
  - Completed
- Data persistence using `localStorage`
- Dynamic DOM rendering
- Event delegation for optimized performance
- Responsive user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
